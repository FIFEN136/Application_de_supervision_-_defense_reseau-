# Hyper-Superviseur-R-seau
Le projet reprend l'idée de départ (surveiller le réseau, analyser les ports, envoyer des alertes et garder une trace de tout) et la recentre sur ce qui rend HSR différent des autres outils : la capacité à détecter un changement sur le réseau, à comprendre d'où il vient, et à le documenter précisément pour l'analyser.
